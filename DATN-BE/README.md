## HOW TO RUN PROJECT

### Install dependencies

```bash
npm install
```

## Run project with js

#### Build typescript to js

```bash
npx tsc
```

#### Run project

```bash
node dist/server.js
```

### Run project with nodemon

```bash
npx nodemon dist/server.js
```

## Run project with ts

```bash
npx ts-node ./src/server.ts
```

#### If ts-node is not installed, run:

```bash
npm install -D ts-node typescript
```
